# 용어집 (Glossary)

| 약어 | 영문 | 설명 |
|------|------|------|
| O-RAN | Open RAN | 개방형 무선 접속망 표준 (O-RAN Alliance) |
| O-RU | O-RAN Radio Unit | 무선/RF 유닛 (이 프로젝트) |
| O-DU | O-RAN Distributed Unit | RLC/MAC/L1-high 담당 상위 노드 |
| O-CU | O-RAN Central Unit | RRC/PDCP 담당 |
| P5G | Private 5G | 사설 5G 망 |
| 7.2x | intra-PHY split | DU/RU 간 주파수영역 IQ 분할 |
| eCPRI | enhanced CPRI | 이더넷 기반 프론트홀 전송 프로토콜 |
| C-plane | Control plane | 무선자원 스케줄 제어 |
| U-plane | User plane | IQ 샘플 데이터 |
| S-plane | Synchronization plane | 시간/주파수 동기 (PTP) |
| M-plane | Management plane | NETCONF/YANG 관리 |
| PRB | Physical Resource Block | 12 subcarrier 단위 자원 |
| BFP | Block Floating Point | U-plane IQ 압축 방식 |
| PTP | Precision Time Protocol | IEEE 1588 시간 동기 |
| SyncE | Synchronous Ethernet | 주파수 동기 |
| TAE | Time Alignment Error | 안테나간 시간정렬 오차 |
| JESD204 | JEDEC serial interface | SoC↔트랜시버 고속 데이터 링크 |
| CGS/ILAS | Code Group Sync / Initial Lane Alignment | JESD204 bring-up 단계 |
| SYSREF | System Reference | JESD204 deterministic latency 기준 클럭 |
| LMFS | L/M/F/S | JESD204 lane/converter/frame/sample 파라미터 |
| DFE | Digital Front End | DUC/DDC/CFR/DPD 등 디지털 RF 처리 |
| CFR | Crest Factor Reduction | PAPR 저감 |
| DPD | Digital Pre-Distortion | PA 선형화 |
| DUC/DDC | Digital Up/Down Converter | 표본율/주파수 변환 |
| MCS | Multi-Chip Sync | 트랜시버 동기 절차 |
| SMO | Service Mgmt & Orchestration | O-RAN 관리 오케스트레이션 |
| MPSoC | Multiprocessor SoC | Zynq UltraScale+ (A53+R5+FPGA) |
| PS / PL | Processing System / Programmable Logic | Zynq의 CPU부 / FPGA부 |
