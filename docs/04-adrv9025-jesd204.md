# 04. ADRV9025 RF 트랜시버 & JESD204

## 1. ADRV9025 개요

- Analog Devices의 **4T4R 광대역 RF 트랜시버** (~75MHz–6GHz, 최대 200MHz
  합성 대역폭급). P5G n78/CBRS에 적합.
- 통합: 4×TX, 4×RX, 2×관측 RX(ORX, DPD용), 내부 LO/PLL, AGC.
- 제어: **SPI** (레지스터/프로파일), 데이터: **JESD204B/C** (고속 SERDES).

## 2. 초기화 순서 (ADI API 기준)

실제 양산은 ADI의 `adi_adrv9025_*` API를 사용합니다. 본 저장소는 그
**순서와 단계**를 `hal/adrv9025`에 스텁으로 모델링합니다.

```
1. Pre-MCS init        adi_adrv9025_PreMcsInit()    프로파일/.bin 로드, 클럭 PLL
2. MCS                 multi-chip sync               여러 칩/레인 정렬 (4T4R 단일칩도 수행)
3. Post-MCS init       adi_adrv9025_PostMcsInit()
4. JESD204 bring-up    SERDES/lane 정렬, ILAS, lock 확인
5. RF PLL 설정         캐리어 주파수(LO) 설정
6. TX/RX enable        채널 활성화, AGC/atten 설정
7. (옵션) DPD/CFR      관측 경로 통한 선형화 (PL/DFE 협조)
```

> **프로파일(.profile/.bin)**: ADI **TES**(Transceiver Evaluation Software)로
> 샘플레이트/대역폭/JESD 파라미터에 맞춰 생성합니다. 본 저장소는
> `config/`에 placeholder를 두고 경로만 참조합니다.

## 3. JESD204 링크

```
   Zynq PL (JESD204 IP)  ◀── lanes (예: L=4) ──▶  ADRV9025
        Framer/Deframer        SERDES (수 Gbps/lane)
```

핵심 파라미터 (JESD204 "LMFS" 등):

| 기호 | 의미 | 예시 |
|------|------|------|
| L | lane 수 | 4 |
| M | converter 수 | 8 (4T4R I/Q) |
| F | frame당 octet | 4 |
| S | multiframe당 sample | 1 |
| N/N' | 변환 비트수 | 16 |

bring-up 단계: **CGS → ILAS → user data**. lane 정렬(deterministic latency)이
O-RAN 타이밍 정확도에 직결됩니다.

본 저장소 구현: `src/hal/adrv9025/jesd204.{h,c}` (상태: RESET → CGS → ILAS → DATA).

## 4. HAL API 경계

`include/oru/hal.h` 가 RF 하드웨어 추상화를 정의합니다. 상위 코드
(fronthaul/app)는 다음만 알면 됩니다:

```c
hal_init();                 // 칩 detect, 프로파일 로드, post-MCS
hal_jesd204_bringup();      // 링크 정렬, lock 확인
hal_set_carrier(freq_hz);   // LO 설정
hal_tx_enable(mask);
hal_rx_enable(mask);
hal_tx_iq(ch, samples, n);  // DL: PL DFE로 IQ 푸시
hal_rx_iq(ch, samples, n);  // UL: PL DFE에서 IQ 풀
```

`HAL_SIM`(host 빌드)에서는 위 함수들이 로그를 남기고 가짜 lock/IQ를
반환합니다. `HAL_TARGET`에서는 ADI API/UIO/devmem로 실제 HW에 연결합니다.

- [ ] TES 프로파일을 샘플레이트/BW에 맞게 생성 → `config/`에 배치
